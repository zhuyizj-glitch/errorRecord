# 真题重组验证卷（v2.0 入库模型校验）

> 用途：把六份原卷按入库模型重组，逐题标注考点，供人工核对「考点判断」与「形态分类」是否正确。
> 生成日期：2026-11-17
> 状态：**已人工校验通过**（2026-11-17）。形态分类、时代/主题轴、英语双层打标、默写拆分均确认；数学考点统一用「函数的奇偶性」。

## 标注规则

- **【正常入库】**：语篇整题。整篇保存 + 题型 + 难度评级，**不做知识点匹配**（阅读/完形等能力型题目靠「题型 + 评级梯度」推荐）。
- **【知识点】**：独立小题 / 材料组子题。打知识点标签，用于薄弱点精确匹配。
- 历史额外标 **【时代】**（朝代/时期轴）；政治额外标 **【主题】**（模块内的主题轴）。
- 三种形态：`独立小题`（一题一考点）/ `材料组题`（共享材料、子题独立打标）/ `语篇整题`（不可拆分、整篇练）。
- 评级三档：简单 / 中等 / 较难（AI 初评，人工可改）。
